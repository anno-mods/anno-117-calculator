Release 5.0

Exchange format

- Import and export a calculator state as an exchange file shared with the Planner, with a report dialog after import.
- Scoped import: pick which parts of a file to apply (islands, routes, modifiers, settings) and undo the last import.
- Imports DLC flags, the volcano level, governor supply and ship-based trade routes. Route re-calculation after import is on by default.

Live game connection

- New navbar plug button connects to the running game through anno-117-pipe and shows live productivity per factory.
- The button only appears when the calculator runs from a file or localhost.
- New live statistics page with island selection and production/consumption bars per product.

Trade routes

- Route indicators from imported game routes, ship visits and storage history show whether a route's capacity covers the calculated rate.
- The trade routes dialog gets a game-routes tab, offload and utilization columns, filters and sorting, plus an icon on product tiles.
- Multi-source game routes get one route per source, with the demand split by each source's surplus.
- A built producer stays the default supplier.

Population dialog

- Need attribute columns with totals over all residences. Area effects and specialists show the same columns.
- DLC icons moved into the name cell.

Factories and effects

- New Boost sources section in the factory dialog lists items, range effects and permanent effects behind a factory's productivity.
- Harvest season and volcano effects now appear only as permanent effects in the factory dialog.
- Fixed coal consumption per working building ignoring cycle time and boost.
- Several item targets were listed twice and are now listed once.
